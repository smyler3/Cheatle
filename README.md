# Cheatle
A daily game combining the gameplay of Boggle with elements of Scrabble. 

***Built using: React, TypeScript, CSS, and Express***

[Link to project](https://cheatle.talymmyler.com/)

## How to run locally
> ***Note:*** This app requires the backend repo to run, this can be found at https://github.com/smyler3/cheatle-api.
### 1. Fork this repo

### 2. Install dependencies
```bash
npm install
```

### 3. Add a .env with a key to point towards your backend
```bash
VITE_API_URL=<your backend url>
```

### 4. Start the app
```bash
npm run dev
```
